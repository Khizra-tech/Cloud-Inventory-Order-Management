# Cloud-Based Inventory and Order Management System

## Overview
A business-focused application for managing product Inventory, tracking orders,and identifying low-stock products.

## Objectives
Maintain product record and stock quantities.
Track customer orders and inventory changes.
Explore cloud hosting, APIs, Databases, and security.
Document the architecture, deployment, and cost considerations.

## Technology Stack
Cloud: Amazon Web Series (AWS)
Backend: Python
Database: To be selected during implementation
Version Control: Git and Github

## Project status
Planning and cloud fundamentals
